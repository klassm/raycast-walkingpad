# Raycast WalkingPad

## Features

- Set WalkingPad speed level
- See current steps, distance, duration and speed

## Requirements

- The [WalkingPad macOS client](https://github.com/klassm/walkingpad_macos_client) must be installed. If it is not running, the extension starts it automatically. Commands fail with a proper error if the client is unreachable or the treadmill is not connected via Bluetooth.

## Installation

Clone this repository and run `npm install && npm run dev`.
